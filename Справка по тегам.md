# Теги

**Теги** - часть навигации в архиве. Все файлы можно отфильтровать по тегам
## Теги типа

- #сообщение - файл является переписанным из Discord сообщением (единственным)
- #статья - файл является полностью переписанной статьёй о персонаже, государстве и др; Может включать несколько сообщений
- #навигация - новая мета, настроченная для навигации по архиву
