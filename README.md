# Millenium Archive
Это WIP-архив дискорд-сервера "Миллениум", закрытого.

Цель создания: сохранение воспоминаний и длинной сюжетной линии, создававшейся коллективно, в безопасном формате локального md-хранилища для программы Obsidian. Сохраняются записи об авторах оригинальных сообщений и датах отправки, а также 90% ссылок и оригинальное медиа (изображения, музыка, видео). НОН-РП контент, отправляемый в РП-каналах также будет записан.

В хранилище включены:

- Тема Royal Velvet
- Плагин Iconize

Часть форматирования написана с помощью Markdown, часть - с помощью HTML, так как Obsidian дозволяет использовать оба языка разметки. По этой причине просмотр в других приложениях может быть затруднителен.
